# 藏書 Windows 桌面版

## 安裝與開啟

執行發行版本提供的 `Cangshu-Setup-<版本>.exe`，完成安裝後可從桌面或開始功能表開啟「藏書」。

第一次設定：在 EPUB 檔案上按右鍵，選擇「開啟檔案」→「選擇其他應用程式」→「藏書」→「一律使用」。
也可從藏書的「檔案 → 設定預設閱讀器」開啟 Windows 設定，搜尋 `.epub` 並選擇藏書。

雙擊 EPUB 會啟動藏書並匯入、轉換、開啟；相同內容不會重複加入書庫。再次雙擊另一個 EPUB 會沿用現有視窗。
程式內可使用 Ctrl+O、匯入按鈕或拖曳檔案。書籍超過 1 GB 時請先拆分再匯入。

## 資料

桌面書庫與設定儲存於 `%APPDATA%\CangshuReader`，不依賴安裝目錄。更新程式或解除安裝不會主動清除此資料夾。
瀏覽器版本的書庫不會自動出現在桌面版，請重新匯入原始 EPUB。原始檔案不會被修改或移動。
備份時先關閉藏書，再備份整個資料夾。Webfont 首次載入需要網路；離線閱讀使用本機備援字體。

## 建置

在本資料夾執行：

```powershell
npm ci
npm test
npm run dist
```

Node.js 僅用於開發與打包；安裝後的使用者不需要 Node.js 或伺服器。
`win-unpacked` 是未安裝測試版，需保留整個資料夾後執行 `Cangshu.exe`。
目前發佈未使用程式碼簽章，因此 Windows 可能顯示未知發行者。沒有修改 Windows 的安全設定。
