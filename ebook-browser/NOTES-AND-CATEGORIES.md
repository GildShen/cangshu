# 筆記與分類

## 螢光筆

選取書中文字後按右鍵，點「螢光筆」使用目前顏色，或直接點八色色票套用標記。「自訂顏色」會開啟顏色對話框。選單支援方向鍵、Enter 與 Escape，點選外部或捲動時會關閉。未選文字時保留原本右鍵行為。

工具列仍保留螢光筆入口，可設定預設顏色，或從清單變更與刪除既有標記。

標記儲存在本機，重新開啟會還原。網頁版與 EPUB 原版分別保存標記，不會互相轉換，也不包含於離線 ZIP 匯出。需要支援 CSS Custom Highlight API 的瀏覽器；桌面版已內建支援。圖片中的文字無法直接標記。

## 閱讀筆記

閱讀工具列的筆記圖示可開啟目前書籍的筆記。先選取書中文字，再按筆記圖示，即可將引文與筆記一起儲存；不選文字也能新增筆記。

每則筆記保存當時的章節與閱讀位置，可編輯、刪除或透過定位圖示返回。網頁模式保存章節與捲動比例，EPUB 模式保存閱讀位置 CFI；不會在原文中加入永久螢光標記。

## 書櫃分類

書櫃左側顯示資料夾，點選可篩選書籍。將書本拖入資料夾即可歸類，拖入「未分類」即可取消歸類；也能使用書本下方的「移至資料夾」圖示操作。側欄上方的資料夾圖示可新增、重新命名與刪除分類。刪除分類不會刪除書籍。每本書目前可放入一個資料夾。

## 資料保存

資料保存在目前瀏覽器或桌面程式的本機資料庫，不會上傳，也不會寫入原始 EPUB。網頁版與桌面版的資料庫彼此獨立。既有書籍與閱讀進度會在資料庫升級時保留。

目前匯出的離線網頁 ZIP 不包含筆記與書櫃分類。清除瀏覽器網站資料會移除本機書庫與筆記。
