# PDF 閱讀

「匯入書籍」接受 EPUB 與 PDF。PDF 保留原始版面，與 EPUB 共用書櫃、分類、筆記及螢光筆功能。

- 頁碼輸入、方向鍵、Page Up / Page Down 與底部按鈕可換頁。
- 支援符合頁寬、固定縮放倍率、向右旋轉與全螢幕。
- 側欄可切換文件目錄及按需載入的頁面縮圖。
- 搜尋會循環尋找下一個含關鍵字的頁面，不會逐一列出頁內所有命中。
- 選取 PDF 文字後按右鍵可使用螢光筆；筆記保存頁碼，可返回該頁。
- 本機保存頁碼、縮放、旋轉、筆記與標記，不修改原始 PDF。

不提供 OCR、PDF 轉網頁排版、表單填寫、數位簽章或含標註 PDF 匯出。掃描 PDF 可以觀看、旋轉及新增頁面筆記，但沒有可選取文字時無法搜尋或文字標記。加密 PDF 尚未提供密碼輸入介面。

桌面安裝檔註冊 EPUB 與 PDF 檔案類型；Windows 預設開啟程式仍須由使用者選擇。建議使用桌面版以完整載入本機 PDF 字型及解碼資源。

渲染核心採用 Mozilla PDF.js，隨程式提供本機執行檔、字型、CMap 與解碼資源；授權位於 vendor/pdf/LICENSE。未使用線上文件轉換服務。
