# AI 閱讀助理

此功能僅在藏書桌面版執行，支援 Codex CLI 與 OpenAI API。兩者都會將選取文字送至雲端，並非離線模型。Codex CLI 使用其登入身份與額度；OpenAI API 不需要安裝 Codex，但須設定自己的 API 金鑰，並另外按 API 用量計費。

## 操作

選取 EPUB、網頁閱讀或文字型 PDF 中的文字，按右鍵選擇「AI 翻譯」、「AI 解釋」或「AI 摘要」。首次執行會確認是否將選取文字送至 Codex。

右側面板顯示來源書籍、章節／頁碼、引文及 AI 回覆，可重試、取消、複製，或按「存成筆記」。筆記儲存至原來源書籍，即使等待期間切換到其他書籍也不會存錯。AI 回覆可能有誤，應與原文對照。

右側設定可切換引擎。Codex CLI 可檢查登入狀態、選擇 codex.exe 與指定模型。未登入時，請先在終端機執行 `codex login`。模型留空使用 CLI 內建預設；此整合不繼承個人 config.toml 的模型、外掛或 MCP 設定。需使用支援 `--ignore-user-config` 與 `--ephemeral` 的近期 CLI。

OpenAI API 可填入模型 ID 與 API 金鑰，預設模型為 gpt-4.1-mini。金鑰使用 Electron safeStorage 的 Windows 系統加密保存在使用者資料目錄，不會寫入設定 JSON、書籍或筆記，也不會由主程序回傳給網頁。金鑰輸入留空會保留既有金鑰；可用垃圾桶按鈕移除。儲存設定只檢查本機狀態，不代表已驗證 API 連線與模型權限。

## Token 用量

每次回覆下方顯示服務回報的輸入、輸出及總 Token。可用時也顯示快取輸入與推理輸出，這兩項已包含於輸入／輸出，不重複加總。CLI 從 JSONL turn.completed 事件取得數字，API 使用 Responses API 的 usage。

輸入包含系統提示等額外內容，不只選取文字。數字是這次工作的用量，不是帳戶總用量，也不是費用或剩餘額度。未回報時顯示「未回報」，不冒充零或估算值；取消、逾時及失敗仍可能已產生服務端用量。存成筆記時一併保存用量中繼資料。

## 範圍與安全

- 每次只送出選取文字，最多 20,000 字，不會自動上傳全書。
- 不提供 OCR；掃描 PDF 沒有文字層時不能圈選圖片中文字。
- 使用獨立暫存工作目錄、唯讀沙箱、非互動執行、stdin 傳遞內容。
- 關閉 shell、瀏覽器、外掛、hooks、MCP apps 等工具能力；將書籍內容明確視為不可信引文。
- 不修改既有 Codex 設定或複製登入憑證。
- 同時一件工作，180 秒逾時，可取消；CLI 輸出先以純文字呈現。
- 回覆只有按「存成筆記」才保存到書庫，CLI 使用 ephemeral 模式；這不代表雲端服務不保留任何資料。
- API 請求固定送至 OpenAI 官方 Responses 端點，不附加工具，設定 store:false；這不等於所有雲端紀錄均零保留。
- 純網頁版與匯出的離線閱讀檔不提供 AI 呼叫。
